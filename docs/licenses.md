# License review

Reviewed 2026-11-07, for GeoFlow 0.2.0, in [Phase 10](phase_10.md).

This is an engineering check of what GeoFlow ships against each license's plain terms. It isn't legal advice.

## Conclusion

GeoFlow can be distributed under the **Apache License 2.0**.
- Everything it ships under another license is permissive: MIT, ISC, BSD-2-Clause, BSD-3-Clause, or MIT chosen from `MIT OR Apache-2.0`. None of them has terms that conflict with Apache-2.0, and none asks more of a binary distribution than keeping its copyright notice and license text.
- The packages it builds on but doesn't ship, Grafana's, are Apache-2.0 and MIT.
- Copyleft code appears only in the development stack (the Grafana and PostGIS Docker images), which the repository names but doesn't redistribute.

All the code in the repository is by one author, so the choice of license is the author's alone.

## What the plugin ships

The plugin archive is `dist/`: GeoFlow's code, MapLibre GL JS with the packages its build inlines, and two small webpack runtime helpers.

The notices file also lists eight packages from MapLibre's dependency tree that its build doesn't inline: `@mapbox/jsonlint-lines-primitives`, `json-stringify-pretty-compact`, `minimist`, `protocol-buffers-schema`, `quickselect`, `require-from-string` and `resolve-protobuf-schema` (all MIT or ISC). The notices plugin adds MapLibre's whole tree, because webpack only sees MapLibre's one prebuilt file. An extra notice is harmless (Phase 10, decision 6).

**How this was checked:**
- MapLibre's source maps list every file in its `maplibre-gl.mjs` and `maplibre-gl-worker.mjs`. They come from MapLibre itself and the 16 packages above it in the table, all declared dependencies. Its other imports (`vitest`, `nise`, `canvas`, `fs` …) are in tests and benchmarks only.
- The single-file builds among those packages (`geojson-vt`, `vt-pbf`, `bidi-js`) were searched for inlined modules. Only `geojson-vt` inlines one: `kdbush`.
- Each package's declared license was compared with its license file. Two differ, both between permissive licenses (the notes above).
- None of the bundled packages has a `NOTICE` file, the Apache-2.0 mechanism that would add further text.

The build's `THIRD_PARTY_NOTICES.txt` is the current list; this table records the review.

## Provided by Grafana at runtime

`@grafana/data`, `@grafana/runtime`, `@grafana/ui`, `@grafana/i18n` and `@grafana/schema` (Apache-2.0), React and React DOM (MIT) and Emotion (MIT) are webpack externals: Grafana supplies them when it loads the plugin, and they aren't in `dist/`. Grafana itself is AGPL-3.0 (open-source edition). A plugin reaches it only through these Apache-2.0 packages, which Grafana Labs publishes for third-party plugins under any license.

Installing GeoFlow's dependencies also installs about 450 packages that come with Grafana's packages. They don't ship, and their licenses are Grafana's concern.

## Data and images

- **Map data.** The default basemap shows OpenStreetMap tiles. The data is under the Open Database License, which asks for visible attribution: "© OpenStreetMap contributors" shows in the map's corner whenever the default basemap is used, and is in `NOTICE` and the README. The tiles come from the OpenStreetMap Foundation's servers, whose usage policy `NOTICE` links to. The plugin ships no map data.
- **Fixture data** (`docker/postgres/init/`) is GeoFlow's own: a fictional fiber network, drawn by hand rather than traced from real buildings, and 100k generated points.
- **Test images.** The e2e tests replace map tiles with `tests/fixtures/tile.png`, a plain gray tile made for the tests, so the stored screenshots contain no OpenStreetMap tiles.
